About

I'm a student working at the intersection of robotics competition engineering, Android development, and systems-level programming. My work spans YOLO-based perception pipelines, ROS2 + Unity integration, real-time WebSocket architectures, and Kotlin apps built for high-pressure competition environments.

I gravitate toward problems that reward structural and strategic analysis over quick fixes — whether that's reverse-engineering a joystick command bitmask, designing an event-log database schema for a match scouting app, or working out rule-exploitation strategy for a robotics competition ruleset.

Outside of competition work, I also build tools for coursework and everyday problems — from numerical methods solvers to interactive algorithm visualizations.

Robocon 2026 — "Kung Fu Quest"

Perception and strategy systems for ABU Robocon's competitive robot. Trained a YOLO-based detector for occluded scroll targets, built a Unity + ROS2 camera pipeline (MJPEG snapshot streaming with server-side rotation baked into shader transforms), and debugged low-level joystick command bitmasking for combo-input detection.

Full-Stack · Real-Time Systems

Robocon 2027 — Match Scouting App

Designing a live timer and scouting system for tracking robot performance metrics mid-match — zone transit times, handling times, malfunction recovery — across four concurrent observers. Built on Next.js + WebSockets with a local-server architecture and an append-only event-log database for full match replay.

Next.jsTypeScriptWebSocketsSQLite

NetalGuard

A non-contact smart bassinet system for neonatal sepsis monitoring in underserved healthcare settings, built for the Gemastik IoT competition. Uses ballistocardiography (BCG) sensing combined with a multimodal cross-attention transformer to generate a real-time Sepsis Suspicion Risk Score.

IoTTransformersSignal Processing

Set up a LiDAR-Inertial-Visual Odometry pipeline on ROS2 using an Intel RealSense D455 camera for the visual and inertial estimation side — part of ongoing work toward robust real-time localization for competition robots.
